# Ma Boutique

Boutique en ligne de chaussures et de vêtements, avec des prix en FCFA.

**Voir le site : [kouassi-morel.github.io/Ma-Boutique](https://kouassi-morel.github.io/Ma-Boutique/)**

## Fonctionnalités

- Page d'accueil avec bannière, ventes flash et zones par marque (Nike, Adidas, Jordan)
- Catalogue avec filtres (catégorie, marque, prix, note) et recherche
- Fiche produit avec produits similaires
- Panier enregistré dans le navigateur
- Commande par WhatsApp
- Menu adapté au téléphone

## Technologies

HTML, CSS et JavaScript (sans framework).

## Ce que j'ai appris

- Construire des pages à partir d'un fichier de données
- Gérer un panier avec le localStorage
- Utiliser Git et GitHub, et publier avec GitHub Pages
